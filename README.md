# Resume Tailor
从JD出发的个性化定制简历修改工具。一键把JD翻译成“人话”，再基于你的真实经历生成“针对这个岗位的简历判断以及定制修改方案”。
Resume Tailor 不是简单的AI 润色简历工具，而是一个帮助你判断“这个岗位到底在做什么、我是否值得投、简历里哪些经历该删/改/补”的求职工作台。

## 🔧快速开始

```bash
git clone <repo-url> && cd resume-tailor
npm install
npm run start
```
打开本地页面后，按下面流程使用：
0. 配置你的APIkey。
1. 上传简历（HTML 或 PDF），完善你的个人素材库（简历上没有的内容，也许是不匹配某个求职方向，但可能是另一个角度是你的闪光点）
2. 粘贴目标 JD，进入分析页面
3. 确认岗位判断和差距清单
4. 生成逐条修改方案，逐条确认与应用
5. 下载或预览最终版本

## ✨核心功能价值

很多人投简历其实问题出在没有彻底理解JD在说什么。
- JD 里写的术语、空话和岗位描述看起来很像，但实际并不等于真实工作
- 一份简历能通用很多岗位，但不能真正“对上”某个岗位，逐个JD手动改简历又太浪费时间
- 很多工具只会给你“润色后的词”，却不会告诉你“这个岗位实际上看重什么”
Resume Tailor 的思路是：先理解岗位，再判断与你的能力是否匹配，再做定制化针对每个JD修改。

### 1. 帮你读懂 JD
系统会把 JD 拆成几个关键层面：
- 岗位定性：职位族、级别、工作性质、主要产出物
- 团队画像：这个岗位的业务线，服务对象是谁、为什么存在
- 职责翻译：把抽象职责还原成真实工作场景
- 交互画像：这个岗位每天常和谁打交道，沟通属性是什么
- 典型工作日：岗位日常会怎么运作

### 2. 判断匹配
系统会基于你的简历和素材库中的个人信息，给出针对这个JD与你匹配度的定性判断，并且给出目前的差距在哪里
- A：值得投
- B：改后投
- C：观望
- D：不建议投
这样你可以直接判断：这是措辞问题，还是主线不对，还是根本不匹配。

### 3. 定制简历，而非全文重写
Resume Tailor 的修改策略分三档：
- 措辞微调：方向基本对口，只是想法没说清
- 换主线：方向相近，但主线不对，需要重排经历
- 大改重构：删无关经历，补真实素材，重新组织主线
重点是：
- 删无关、改相关、补缺口，用更细节的修改，而不是“一次性生成一份看起来更像目标岗位的全文”。

### 4. 用户确认每一条修改
修改方案是逐条 diff，而不是一次性输出整份大改稿：
- 每条修改都附带原因，可勾选/取消/编辑，也可按你的要求只重写某一条
这种设计让 AI 更像“建议与校验工具”，而不是“黑盒重写器”。

### 5. 简历定制延伸到投后
生成修改之后，还支持投递追踪与面试准备：
- 记录投递状态
- 生成下一轮面试的准备
- 面试前 checklist等
也就是说，它不仅能“改简历”，还能帮你追踪改完的情况，助你后续顺利过关。


## ❓和直接贴JD给AI不一样在哪里

直接贴 JD 给 AI，AI 往往只会“润色措辞”，缺少岗位真实信息的还原。而且AI并不了解你的全部，这个工作台可以安全的沉淀你的个人信息，你的多方面能力，
它不是“AI 帮你改一句话”，而是“帮你把岗位理解透，用真实证据定制简历”。

## 输入方式

Resume Tailor 支持两种主流输入方式：
- HTML：主链路，适合长期维护和逐条精确编辑
- PDF：兼容入口，适合导入已有 PDF 简历后进行结构化解析

HTML 是更适合��期定制的格式，因为它允许精确定位文本节点，逐条替换并保留原版式；PDF 更像“导入旧简历”的补充入口。


## 架构概览

```text
public/
  index.html          页面结构与向导入口
  app.js              前端交互、状态管理、PDF 解析、diff 与预览
  style.css           样式

src/
  server.ts           Express / Vercel API
  analyze.ts          LLM 分析与结构化输出
  prompts.ts          JD 解构、筛选判断、编辑策略、面试 prep prompts
  apply.ts            HTML 文本节点定位和精确替换
  structuredApply.ts  结构化简历的按下标修改逻辑
  api/index.ts        Vercel 入口

storage/
  IndexedDB          浏览器本地存储，保存简历、素材、投递记录和配置
```
